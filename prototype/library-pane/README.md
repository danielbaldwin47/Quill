# Library pane directions — a throwaway prototype (#438)

Six visual directions for the Library pane, generated as design-canvas artboards.
`python3 gen.py` rewrites every `.dc.html` and `canvas.json` from the palettes and
content at the head of the script; `node shoot.mjs <board>.dc.html ...` renders a
board to PNG with the repo's `playwright-core` and `/usr/bin/chromium`.
